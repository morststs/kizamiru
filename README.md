# Kizamiru

チェックリストを作って、ブラウザに保存して使えるサービス。

**<https://kizamiru.e17.click>**

- アカウント登録は不要。チェックはブラウザの localStorage にだけ保存される。
- リストは JSON でエクスポート／インポートできる。
- 作ったリストを公開すると、内容から決まるハッシュで誰でも開けるようになる。
  公開には Google ログインが必要。

このリポジトリはビルド成果物の配置先で、中身は自動生成されたファイル。
直接編集しても次のデプロイで上書きされる。

公開リストの取得と公開は Cloudflare Workers 上の API が担う。
ソースは別リポジトリ（プライベート）。
